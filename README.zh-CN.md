# oh-my-pi 简体中文版（说明书）

> **分支声明**：本仓库是 [can1357/oh-my-pi](https://github.com/can1357/oh-my-pi) 的**简体中文分支（Fork）**，由 [@hi5548](https://github.com/hi5548) 维护。在原版基础上，终端可见界面已全面中文化；本页所有安装命令安装的都是**中文版**。原版（英文）请访问上游仓库。

**当前同步的上游版本**：18.2.1（上游发布于 2026-09-15）。

## 这是什么

oh-my-pi 是一个带完整终端界面的 AI 编程代理工具。这个分支把它变成了中文版：

- 模型选择界面与 `/models` 管理页（模型详情、角色、备用模型链、服务商状态）
- `/agents` 代理管理页、顾问（advisor）配置页
- 斜杠命令介绍与实时状态（输入 `/` 弹出的全部命令介绍）
- CLI 帮助：命令介绍、环境变量说明、工具说明
- 设置页、欢迎页、首次启动向导、暂停界面、OAuth 登录等
- 通用弹窗：历史搜索、会话移动、扩展控制中心等
- 后续新增面板：`/btw` 侧边问答、Agent Hub、用量面板、会话信息、回退选择器、复制菜单、`omp git` 全屏界面

命令名（例如 `/settings`、`/model`）、快捷键、模型名、服务商名、文件路径、代码、工具输出和协议字段保持原样，保证原有工作方式不变。

## 一键安装

需要 macOS 或 Linux。在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/hi5548/oh-my-pi/main/install-cn.sh | bash
```

如果上面的地址访问不畅，也可以手动克隆后运行：

```sh
git clone https://github.com/hi5548/oh-my-pi.git
cd oh-my-pi
bash install-cn.sh
```

脚本会自动完成：安装 Bun 运行环境（如缺失）→ 下载源码 → 安装依赖（默认下载源不可用时自动改用国内镜像）→ 下载平台加速引擎 → 构建中文版 → 创建 `omp` 命令 → 验证安装。

**系统要求**：macOS 或 Linux · bun ≥ 1.3.14（脚本会自动安装）· Windows 暂不支持。

## 使用入门

安装完成后，在任意位置输入：

```sh
omp
```

即可启动中文版。第一次运行会出现中文设置向导（选择主题、登录服务商等）。会话中输入 `/` 可以看到全部中文命令介绍；`/help` 查看快捷键。

## 更新

本中文版跟随上游官方更新，需要重新同步、补翻新增文案并重新构建。**不建议自行运行官方英文安装命令更新**（会装回英文版）。需要更新时联系本仓库维护者处理即可。

## 卸载

```sh
rm ~/.bun/bin/omp          # 删除 omp 命令
rm -rf ~/.omp/oh-my-pi     # 删除安装目录
```

聊天记录等个人数据存放在 `~/.omp` 的其他目录中，不会被上面两条命令删除。

## 常见问题

**`curl -fsSL https://omp.sh/install | sh` 能装中文版吗？**

不能。那是原作者官方渠道的命令，安装的是英文原版，并且可能覆盖本分支创建的 `omp` 命令。请使用本页的安装命令。

**安装脚本中途失败怎么办？**

脚本在依赖下载失败时会自动切换国内镜像重试；如果仍失败，重新运行一次脚本即可（已完成的步骤会自动跳过或快速重做）。

## 手动构建（开发者）

```sh
bun install
bun --cwd=packages/coding-agent run gen:tool-views
bun --cwd=packages/coding-agent run gen:bundle
./omp-cn
```

> **关于自动化测试**：本分支只改界面文字，而上游测试里有大量用例直接断言英文界面文案，因此 `bun test` 会出现一批失败——这是中文化的预期结果，**不代表功能异常**。本分支不跟进修复上游测试，以免每次同步上游时产生大量冲突。
